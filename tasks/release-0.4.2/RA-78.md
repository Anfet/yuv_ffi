**Status:** REVIEW · **Tier:** T3 · **Owner:** GPT-6 Luna · **Execution Mode:** FAST · **Review Tier:** T2 · **Depends On:** RA-70 · **Rejection Count:** 0

#### Problem / Goal
Вынести джобу `example-analyze-and-build` из общего `ci.yml` в отдельный workflow: он запускается только на свои пути и не зависит от чужих платформ.

#### Architect Decision
По соглашениям RA-70.
- Файл `.github/workflows/ci-example.yml`, одна джоба, раннер `[self-hosted, Windows, X64]`, матрица Flutter 3.41.0 / 3.44.9.
- В YAML только checkout, выбор раннера и вызов `tool/ci/example.ps1` (Linux — `.sh`). Логика — в скрипте.
- Скрипт выполняет: `flutter analyze` и `flutter build web` в `example/`.
- Маршрут по префиксу ветки (RA-53): `all/**` и ключ этого workflow; `release/**`/`main` — всегда. Пути платформы (`example/**`, `lib/**`, `pubspec.yaml`) должны совпадать с картой `tool/ci/scope_guard.sh`; расхождение правится в карте, а не в workflow.

#### Scope
`.github/workflows/ci-example.yml`, `tool/ci/example.*`, удаление джобы `example-analyze-and-build` из `ci.yml`. Чужие workflow и скрипты не трогать.
