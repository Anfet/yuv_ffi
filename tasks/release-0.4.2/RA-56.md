# RA-56 — Ускорить Web-проверку
**Status:** REWORK · **Tier:** T2 · **Owner:** Terra (T2, queued) · **Execution Mode:** STANDARD · **Review Tier:** T1 · **Depends On:** RA-55 · **Rejection Count:** 1

#### Problem / Goal
Web-джоба идёт ~18 минут, остальные — 1–5. Разбор полного прогона [36561975316](https://github.com/Anfet/yuv_ffi/actions/runs/36561975316):
- «Required Web integration gate» — 10,5 мин: 13 файлов `integration_test/*_web_test.dart` запускаются по одному через `flutter drive`; каждый компилируется заново (~32 с «Waiting for connection from debug service»), сами тесты — ~11 с на файл;
- «Web reference matrix» — 6,3 мин: компиляция 37 с и 5,6 мин выполнения 119 случаев в debug-режиме (для сравнения: проба на 1188 случаев выполняется за 38 с).

#### Architect Decision
1. **Одна компиляция вместо тринадцати.** Добавить `example/integration_test/all_web_test.dart`, который вызывает `main()` каждого `*_web_test.dart` внутри своей `group(<имя файла>)`. Файлы, которым нужна чистая страница (проверки загрузки WASM и жизненного цикла загрузчика: `wasm_bootstrap_web_test.dart`, `wasm_loader_lifecycle_web_test.dart` и те, что исполнитель найдёт по падениям в общем запуске), остаются отдельными целями. Список отдельных целей — явный, в самом скрипте джобы, с причиной в комментарии.
2. **Гейт не теряет файлы.** Проверка в джобе: каждый `*_web_test.dart` либо подключён в `all_web_test.dart`, либо есть в списке отдельных целей; иначе джоба красная. Имя файла `all_web_test.dart` не должно попадать под маску `*_web_test.dart` дважды — исключить его из перебора явно.
3. **Матрица 119 не в debug.** Запускать `reference_web_conversions_test.dart` с `--profile` (или `--release`, если profile не поддерживается `flutter drive` для web-server); вердикт по-прежнему через `tool/ci/drive.sh` (exit 0 и `All tests passed`).
4. Число тестов и строки итогов (`YUV-12 summary: executed=… failed=…`, итог пробы 1188) не меняются — сравнить с прогоном до изменения.
5. Код пакета не менять (замороженные пути RA-55).
