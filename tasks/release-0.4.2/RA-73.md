# RA-73 — Workflow macOS native
**Status:** TODO · **Tier:** T3 · **Owner:** — · **Execution Mode:** FAST · **Review Tier:** T2 · **Depends On:** RA-70 · **Rejection Count:** 0

#### Problem / Goal
Вынести джобу `macos-native-smoke` из общего `ci.yml` в отдельный workflow: он запускается только на свои пути и не зависит от чужих платформ.

#### Architect Decision
По соглашениям RA-70.
- Файл `.github/workflows/ci-macos.yml`, одна джоба, раннер `[self-hosted, macOS, X64]`.
- В YAML только checkout, выбор раннера и вызов `tool/ci/macos.sh`. Логика — в скрипте.
- Скрипт выполняет native build и `flutter build macos` в `example/`; запускает app smoke и `*_native_test.dart` через `flutter drive` из `example/`, принимая результат только при exit code `0` и строке `All tests passed`.
- Маршрут по префиксу ветки (RA-53): `all/**` и ключ этого workflow; `release/**`/`main` — всегда. Пути платформы (`src/**`, `macos/**`, `lib/src/yuv/impl/io/**`, `test/probe/**`, `example/integration_test/**`, `example/macos/**`) должны совпадать с картой `tool/ci/scope_guard.sh`; расхождение правится в карте, а не в workflow.

#### Scope
`.github/workflows/ci-macos.yml`, `tool/ci/macos.sh`, удаление джобы `macos-native-smoke` из `ci.yml`. Чужие workflow и скрипты не трогать.

#### Definition of Done
- [ ] `bash tool/ci/macos.sh` зелёный локально (лог в отчёте)
- [ ] Workflow зелёный на ветке карточки
- [ ] Push только в `*.md` и push в пути другой платформы его не запускают (ссылки на run или их отсутствие)
- [ ] Джоба `macos-native-smoke` удалена из `ci.yml`
