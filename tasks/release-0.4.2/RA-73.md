# RA-73 — Workflow macOS native
**Status:** TODO · **Tier:** T3 · **Execution Mode:** FAST · **Review Tier:** T2 · **Depends On:** RA-70 · **Rejection Count:** 0

#### Problem / Goal
Вынести джобу `macos-native-smoke` из общего `ci.yml` в отдельный workflow: он запускается только на свои пути и не зависит от чужих платформ.

#### Architect Decision
По соглашениям RA-70.
- Файл `.github/workflows/ci-macos.yml`, одна джоба, раннер `[self-hosted, macOS, X64]`.
- В YAML только checkout, выбор раннера и вызов `tool/ci/macos.ps1` (Linux — `.sh`). Логика — в скрипте.
- Скрипт выполняет: native build; `flutter build macos` в example; app smoke и `*_native_test.dart` через `tool/ci/drive`.
- `paths`: `src/**`, `macos/**`, `lib/src/yuv/impl/io/**`, `test/probe/**`, `example/integration_test/**`, `example/macos/**`, сам workflow и скрипт; значения сверить с картой RA-62.

#### Scope
`.github/workflows/ci-macos.yml`, `tool/ci/macos.*`, удаление джобы `macos-native-smoke` из `ci.yml`. Чужие workflow и скрипты не трогать.

#### Definition of Done
- [ ] `tool/ci/macos` зелёный локально (лог в отчёте)
- [ ] Workflow зелёный на ветке карточки
- [ ] Push только в `*.md` и push в пути другой платформы его не запускают (ссылки на run или их отсутствие)
- [ ] Джоба `macos-native-smoke` удалена из `ci.yml`
