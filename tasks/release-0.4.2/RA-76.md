# RA-76 — Workflow Linux (единственный hosted)
**Status:** IN_PROGRESS · **Tier:** T3 · **Owner:** GPT-6 Luna · **Execution Mode:** FAST · **Review Tier:** T2 · **Depends On:** RA-70 · **Rejection Count:** 0

#### Problem / Goal
Вынести джобу `linux-native-smoke` из общего `ci.yml` в отдельный workflow: он запускается только на свои пути и не зависит от чужих платформ.

#### Architect Decision
По соглашениям RA-70.
- Файл `.github/workflows/ci-linux.yml`, одна джоба, раннер `ubuntu-latest` — единственная GitHub-hosted джоба (правило Engineer).
- В YAML только checkout, выбор раннера и вызов `tool/ci/linux.ps1` (Linux — `.sh`). Логика — в скрипте.
- Скрипт выполняет: native build; sanitizer CTest; VM smoke; Linux app smoke и `*_native_test.dart` через `tool/ci/drive.sh`.
- Маршрут по префиксу ветки (RA-53): `all/**` и ключ этого workflow; `release/**`/`main` — всегда. Пути платформы (`src/**`, `linux/**`, `lib/src/yuv/impl/io/**`, `test/probe/**`, `example/integration_test/**`, `example/linux/**`) должны совпадать с картой `tool/ci/scope_guard.sh`; расхождение правится в карте, а не в workflow.

#### Scope
`.github/workflows/ci-linux.yml`, `tool/ci/linux.*`, удаление джобы `linux-native-smoke` из `ci.yml`. Чужие workflow и скрипты не трогать.

#### Definition of Done
- [ ] `tool/ci/linux` зелёный локально (лог в отчёте)
- [ ] Workflow зелёный на ветке карточки
- [ ] Push только в `*.md` и push в пути другой платформы его не запускают (ссылки на run или их отсутствие)
- [ ] Джоба `linux-native-smoke` удалена из `ci.yml`
