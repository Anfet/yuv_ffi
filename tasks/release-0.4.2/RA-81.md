# RA-81 — CI только на release/main
**Status:** MERGE_CI_PENDING · **Tier:** T2 · **Owner:** Engineer · **Execution Mode:** STANDARD · **Review Tier:** T1 · **Depends On:** — · **Rejection Count:** 0

#### Problem / Goal
Маршрутизация по префиксу ветки (D-5) запускала CI на каждый push карточки. Ключ `all` обязателен для правок в `src/**`, `lib/src/yuv/impl/io/**`, `test/probe/**`, поэтому каждая попытка стоила 9 workflow, и ещё 9 — слияние в release. Документационные коммиты в release тоже запускали полный набор. 30.09.2026 было 144 запуска.

#### Architect Decision (Engineer D-9)
- Триггеры push всех workflow: `release/**`, `main`, `ci/**`. `ci/**` — явное включение для карточек, которые меняют CI.
- Одинаковый `paths-ignore: ["**/*.md", "doc/**", "tasks/**"]` во всех workflow.
- Шаг `Check branch scope` удалён из workflow; условия `if:` по префиксу ветки удалены. `tool/ci/scope_guard.sh` сохранён как карта путей для локальной проверки (RA-62).
- `workflow_dispatch` в `ci.yml` оставляет только существующие джобы `bindings` и `linux`.
- Правила 2–4 плана и раздел «CI соглашения» в `AGENTS.md` переписаны под D-9.

#### Scope
`.github/workflows/*.yml`, `AGENTS.md` (CI соглашения), `pre-release-todo.md`, `tasks/release-0.4.2/RA-62.md`, эта карточка.

#### Definition of Done
- [x] Все 9 workflow разбираются YAML-парсером; триггеры — ровно `release/**`, `main`, `ci/**` и `workflow_dispatch`; `paths-ignore` одинаковый; шагов `scope_guard` нет.
- [ ] Полный release CI зелёный на SHA слияния RA-81.
- [ ] Следующий документационный коммит в release не создаёт runs.
