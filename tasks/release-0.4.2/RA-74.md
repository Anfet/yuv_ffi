# RA-74 — Workflow iOS
**Status:** BLOCKED · **Tier:** T3 · **Owner:** GPT-6 Luna · **Execution Mode:** FAST · **Review Tier:** T2 · **Depends On:** RA-70 · **Rejection Count:** 0

#### Problem / Goal
Вынести джобу `ios-native-build` из общего `ci.yml` в отдельный workflow: он запускается только на свои пути и не зависит от чужих платформ.

#### Architect Decision
По соглашениям RA-70.
- Файл `.github/workflows/ci-ios.yml`, одна джоба, раннер `[self-hosted, macOS, X64]`.
- В YAML только checkout, выбор раннера и вызов `tool/ci/ios.sh`. Логика — в скрипте.
- Скрипт выполняет: `pod install`; app smoke и `*_native_test.dart` на iOS Simulator через `flutter drive` из `example/`, принимая результат только при exit code `0` и строке `All tests passed`; `flutter build ios --no-codesign`.
- Маршрут по префиксу ветки (RA-53): `all/**` и ключ этого workflow; `release/**`/`main` — всегда. Пути платформы (`src/**`, `ios/**`, `lib/src/yuv/impl/io/**`, `test/probe/**`, `example/integration_test/**`, `example/ios/**`) должны совпадать с картой `tool/ci/scope_guard.sh`; расхождение правится в карте, а не в workflow.

#### Scope
`.github/workflows/ci-ios.yml`, `tool/ci/ios.sh`, удаление джобы `ios-native-build` из `ci.yml`. Чужие workflow и скрипты не трогать.

#### Definition of Done
- [ ] `bash tool/ci/ios.sh` зелёный локально (лог в отчёте)
- [ ] Workflow зелёный на ветке карточки
- [ ] Push только в `*.md` и push в пути другой платформы его не запускают (ссылки на run или их отсутствие)
- [ ] Джоба `ios-native-build` удалена из `ci.yml`


#### Executor Report — BLOCKED

- Реализация RA-74 подготовлена: iOS job вынесена в отдельный workflow, а проверки перенесены в `tool/ci/ios.sh`.
- Локальный iOS gate не выполнен: рабочая среда — Windows; доступный `bash` является WSL launcher, и `wsl` сообщает, что Linux distributions не установлены. Команды `pod`, `xcrun`, `xcodebuild` и iOS Simulator локально недоступны.
- `bash tool/ci/ios.sh` требует macOS, CocoaPods, Xcode и доступный iPhone Simulator; запустить его на текущем хосте нельзя. Push и GitHub CI не запускались, поскольку обязательный локальный gate не пройден.
- Требуется: на Mac с Flutter 3.44.9, CocoaPods, Xcode и доступным iPhone Simulator выполнить `bash tool/ci/ios.sh`, сохранить лог и подтвердить успешное завершение; после этого можно push-нуть ветку и проверить workflow.
