# RA-60 — Теги тест-сьюта
**Status:** ARCHITECT_REQUIRED · **Tier:** T3 · **Execution Mode:** FAST · **Review Tier:** T2 · **Depends On:** RA-70, RA-71, RA-72, RA-73, RA-74, RA-75, RA-77, RA-78 · **Rejection Count:** 0

#### Problem / Goal
Любая правка запускает всё: 700+ VM-тестов, 1188 проб, матрицу 119, все платформы. Нужно запускать только то, что относится к изменению.

#### Architect Decision
В `dart_test.yaml` описать теги и отметить каждый файл `@Tags([...])` по правилу:

| Тег | Файлы | Когда |
| --- | --- | --- |
| `smoke` | `native_packaging_smoke_test`, `loader_io_test`, `cmake_sources_test`, `apple_forwarder_sources_test`, `abi_symbol_manifest_test` | каждый push, секунды |
| `contract` | остальные `test/*.dart` | правки `lib/` |
| `probe` | `test/probe/**` | правки `lib/src/yuv/impl/**`, `src/**` |
| `reference` | `reference_*_test.dart` | правки `src/**`, конвертаций |
| `release` | provenance, dry-run, runner-тесты `test/probe/run_*` | только релизная проверка |

`flutter test` без аргументов = `smoke` + `contract` (`release`, `probe`, `reference` исключены по умолчанию через `dart_test.yaml`). Файл без тега — красный тест `test/tags_coverage_test.dart`.

#### Definition of Done
- [ ] Каждый файл имеет ровно один основной тег; `tags_coverage_test` зелёный
- [ ] `flutter test`, `--tags probe`, `--tags reference` дают в сумме то же число тестов, что прежний полный прогон

#### Executor Report
Карточка остановлена до завершения из-за конфликта требований к селекторам тегов.

- Базовая ветка `origin/release/0.4.2` уже содержит актуальные зависимости `RA-70…75, RA-77, RA-78`; менять строку `Depends On` не потребовалось.
- Полный baseline на Windows после локальной сборки native DLL: `flutter test --reporter json` — 731 passed, 0 failed.
- С `include_tags: "smoke || contract"` обычный запуск проходит (569 passed, 0 failed), но partition-команды ниже не могут выполнить DoD.
- `test/tags_coverage_test.dart` проходит при проверке тегов.
- Ограничение `include_tags: "smoke || contract"` в `dart_test.yaml` ограничивает и явный запуск `flutter test --tags probe`: селекторы объединяются как `(smoke || contract) && probe`, после чего runner сообщает `No tests match` (exit 79). Ограничение через `exclude_tags` также имеет приоритет над включённым тегом probe.
- Нужно решить, изменить ли контракт запуска по умолчанию или требование прямых команд `--tags probe` / `--tags reference`; текущая статическая конфигурация не выполняет оба требования одновременно.
