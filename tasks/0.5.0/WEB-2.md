# WEB 2 — Web: оценка паритета WASM с native
**Status:** BLOCKED · **Tier:** T2, Reviewer T1 · **Owner:** APPLE 1 · **Depends On:** WEB 5, APPLE 1 · **Probe:** windows

#### Goal
Web — частичный WASM-бэкенд (README): набор операций сверяется по `YuvCapabilities`, эталонная матрица на Web — 119
случаев против 1188 на native, проверяется только Chrome, `flutter build web --wasm` не поддерживается. Сколько всего
не сходится с native, никто не сводил. Задача — оценить разрыв, а не закрыть его (D-21):

- взять часть операций и раскладок (представительную выборку: конвертации, геометрия, вставка, краевые раскладки —
  padding, pixel stride, нечётные размеры) и проверить на Web против native;
- по выборке оценить, сколько всего не сходится или отсутствует;
- Safari и Firefox, `--wasm` — смоуком: запускается ли, что ломается;
- итог — перечень расхождений с оценкой объёма и рекомендация по каждому: чинить в 0.5.0, после релиза или описать
  в README.

Доведение до паритета — отдельные карточки по итогу оценки. Было WAIT-01.

Этап 7 (D-21), после WEB 5 и APPLE 1.

#### Architect Decision
Черновик. При входе в этап Architect дописывает: состав выборки, способ сверки с native (эталон или прогон тех же
случаев), где фиксируется итог (`doc/`), критерий «чинить в 0.5.0».
