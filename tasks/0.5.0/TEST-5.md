# TEST 5 — Чистка дублирующих тестов
**Status:** BLOCKED · **Tier:** T2 · **Owner:** TEST 1, TEST 2, TEST 7 · **Depends On:** TEST 1, TEST 2, TEST 7

#### Goal
Одна регрессия — одно место, где она ловится (плюс эталон). Убрать тесты, чей контракт уже проверяет другой файл,
и ускорить медленные файлы, не потеряв ни одного контракта. Удаление без доказательства не допускается.

#### Architect Decision
- Кандидаты берутся только из `tasks/0.5.0/TEST-1-inventory.md` (колонка «Предложение»). Новые кандидаты,
  найденные по ходу, сначала дописываются в инвентаризацию с названием покрывающей группы.
- **Правило удаления — доказательство.** Для каждого удаляемого теста или группы назвать регрессию, от которой он
  защищает, и доказать, что остающийся тест (назван в инвентаризации) её ловит. Способ зависит от того, где
  живёт регрессия:
  - **`lib/`** (Dart-граница: перепутанные аргументы, формат, поворот, stride, раскладка) — временная мутация:
    внести ошибку, показать, что падают и удаляемый, и остающийся тест, откатить.
  - **`src/`** (формулы и ядра) — `src/` не правится даже временно (D-17). Доказательство покрытием: остающийся
    тест вызывает ту же операцию с тем же форматом и параметрами (или их надмножеством) и сравнивает весь выход с
    независимым эталоном побайтно или с тем же допуском. Тогда любое изменение выхода, которое ловит удаляемый
    тест, ловит и остающийся. В отчёте — пара «удаляемый случай → покрывающий случай» с параметрами.
  - Если ни один способ не подходит, тест остаётся.
- **Кто остаётся при дублях конвертаций.** Из `conversions_test`, `reference_native_conversions_test`,
  `independent_results_test` и проб основным считается сравнение с эталоном `test/reference/test_pattern_512`
  (его независимость подтверждена TEST 7). Тесты, которые сравнивают native с формулой, переписанной в самом тесте,
  удаляются в пользу эталона, если это доказано по правилу выше.
- **Web.** `test/web/wasm_parity_*` против `example/integration_test/*_web_test`: оставляется вариант, который
  реально выполняется в CI (`tool/ci/web.ps1`); второй удаляется по тому же правилу.
- **Ускорение.** Файлы из раздела «Медленные файлы» инвентаризации: уменьшить вход или матрицу, если
  доказательство по правилу выше сохраняется. Время до и после — в отчёте.
- Удаляемые тесты устаревшего API (`deprecated_api_test`) здесь не трогаются: их убирает CLEAN 2.

#### Scope
- Ветка `task/TEST-5` от `dev`, worktree `.worktrees/TEST-5`.
- `test/**`, `example/test/**`, `example/integration_test/**`; `tasks/0.5.0/TEST-1-inventory.md` (обновить
  строки удалённого и изменённого); эта карточка.
- Большой объём — делить на коммиты по группам (конвертации, геометрия, web, ускорение).

#### Constraints
- `src/` не меняется совсем (D-17). `lib/` в итоговом diff не меняется: мутации в нём только временные. Перед
  каждым коммитом — `git diff --exit-code -- lib src`.
- Контракты из раздела «Контракты без второго покрытия» не удаляются.
- Эталонные артефакты и `golden.json` проб не меняются.
- Теги файлов (TEST 2) сохраняются; новый файл получает тег по правилу TEST 2.
