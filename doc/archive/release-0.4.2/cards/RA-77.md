# RA-77 — Workflow Web/WASM
**Status:** DONE · **Tier:** T2 · **Owner:** — · **Execution Mode:** STANDARD · **Review Tier:** T1 · **Depends On:** RA-70, RA-56 · **Rejection Count:** 0

#### Problem / Goal
Вынести джобу `wasm-web-integration` из общего `ci.yml` в отдельный workflow: он запускается только на свои пути и не зависит от чужих платформ.

#### Architect Decision
По соглашениям RA-70.
- Файл `.github/workflows/ci-web.yml`, одна джоба, раннер `[self-hosted, Windows, X64, web]`.
- В YAML только checkout, выбор раннера и вызов `tool/ci/web.ps1` (Linux — `.sh`). Логика — в скрипте.
- Скрипт выполняет: `flutter pub publish --dry-run` (assets); пересборка WASM на emsdk 3.1.74 и побайтное сравнение с `assets/wasm`; все `integration_test/*_web_test.dart` и матрица 119 через `tool/ci/drive` (ChromeDriver :4444).
- Маршрут по префиксу ветки (RA-53): `all/**` и ключ этого workflow; `release/**`/`main` — всегда. Пути платформы (`src/**`, `lib/src/yuv/impl/web/**`, `assets/wasm/**`, `tool/wasm/**`, `test/probe/**`, `example/integration_test/**`) должны совпадать с картой `tool/ci/scope_guard.sh`; расхождение правится в карте, а не в workflow.

#### Scope
`.github/workflows/ci-web.yml`, `tool/ci/web.*`, удаление джобы `wasm-web-integration` из `ci.yml`. Чужие workflow и скрипты не трогать.
