# Независимая проверка BGRA-04, 27.09.2026

Проверены коммиты `aca3049` (interleaved A/D опыт) и `ca1b26d` (приёмка исполнителем T1). `git diff 99b326b HEAD -- src lib test_native test` пуст: production-код после предыдущего ревью не менялся.

## Результат

На Pixel 3 `8B1X11QLW`, профильная сборка, экран включён и keyguard снят, повторён tight 1920×1080 опыт A (`Uint8List.fromList`) против D (`ByteBuffer` view + `.sublist(0)`). Seeded shuffle распределяет 30 A и 30 D по одному измеряемому циклу. До и после опыта устройство было `Awake`, экран включён. Checksum и независимость копии проверялись после остановки таймера на каждом сэмпле; `All tests passed`.

Причина именно тех чисел не установлена, влияние порядка является правдоподобным объяснением.

## Проверка стенда и контрактов

- Код сравнивает raw native buffer одинаковой длины 8 294 400 байт, готовит seed вне таймера, использует один порядок Fisher–Yates с фиксированным seed и замеряет только создание Dart копии. Формулы A/D совпадают с ранее исследованными кандидатами; `toBgraBytes()` внутри этого микротеста не вызывается.
- Исходный тест пытался вывести большой `raw_sequence` в одной строке `debugPrint`; Android лог обрезал строку до медианы. Исправлен только вывод: короткая сводка печатается отдельно, затем `raw_order` вместе с двумя массивами сэмплов. Последний прогон подтвердил, что обе строки целиком дошли до host лога.
- `flutter analyze integration_test/bgra04_copy_out_ad_interleaved_pixel3_test.dart --no-pub` — 0 issues; `flutter test test/bgra04_copy_out_test.dart -r compact` — 4/4 passed. Production код не менялся.
