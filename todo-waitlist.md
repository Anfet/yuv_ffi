## WAIT-01 — Завершить Web WASM parity

- Статус: WAITLIST; исполнитель: GPT-5.6 Terra; независимая приёмка: GPT-6 Sol.
- Web остаётся частичным backend по принятому контракту 0.4.0. Нужна отдельная матрица оставшихся операций, краевых layout и реальных browser/runtime проверок до заявления о полной parity; AUD-04 должен пока описывать это ограничение честно.

## WAIT-02 — Оценить будущую поддержку Swift Package Manager и iOS 26 Simulator

- Статус: WAITLIST; исполнитель: GPT-5.6 Terra; независимая приёмка: GPT-6 Sol.
- Flutter 3.44.9 при iOS Simulator запуске предупредил об отсутствии SPM support у `yuv_ffi` и о том, что текущие ML Kit зависимости example не поддерживают arm64 для iOS 26+ Simulator. Текущий CocoaPods-путь и smoke на iOS 18.6 проходят после повторной сборки; это задача совместимости будущих окружений, не доказанный дефект текущего native API.
