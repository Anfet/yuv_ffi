# AGENTS Guide

## Generated Bindings Policy

- Do not edit generated FFI bindings manually.
- Protected file: `lib/src/functions/bindings/yuv_ffi_bingings.dart`.
- This file is generated by tooling/plugins (`ffigen`) and manual edits will be overwritten.
- If API changes are needed, update headers/config and regenerate.

## Regeneration

- Config: `ffigen.yaml`
- Typical command: `flutter pub run ffigen --config ffigen.yaml`
